# Getting started

Use MoSt to choose the planet, grid, and components, compile the model,
and prepare the run inputs. The first chapter covers both the graphical
starter and its headless configuration-file option. Continue with experiment
directories before retaining a long simulation or reusing a prepared setup.

```{toctree}
:maxdepth: 1

most
experiments
gui
```

The simulation GUI is optional and separate from the MoSt configuration
window. Once the first setup is familiar, see {doc}`configuration` for
planetary settings, boundary data, parallel/coupled runs, and continuation.
